# QA-проект: тестирование веб-приложения Swag Labs

Личный проект по ручному и автоматизированному тестированию интернет-магазина.

Цель проекта: отработать полный цикл работы тестировщика (от тест-дизайна и тестовой документации до автотестов и баг-репортов).

## Объект тестирования

**Swag Labs**(https://www.saucedemo.com/) — интернет-магазин, созданный компанией Sauce Labs для практики тестирования.

## Содержание

Тест-кейсы [Тест-кейсы_SwagLabs.docx](Тест-кейсы_SwagLabs.docx): 41 тест-кейс по 4 модулям

Чек-листы [Чек-лист_SwagLabs.docx](Чек-лист_SwagLabs.docx): Smoke-тестирование, авторизация, каталог и корзина, оформление заказа

Баг-репорты [Баг-репорты_SwagLabs.docx](Баг-репорты_SwagLabs.docx):7 багов

Автотесты (Python, Selenium, pytest, Page Object). Автоматизированы сценарии: вход, добавление и удаление товаров, оформление заказа, проверка расчёта суммы.
